# Aluco – Name

Entschieden: 2026-11-18

**Aluco** – vom lateinischen Artnamen des Waldkauzes, *Strix aluco*. Der Kauz wacht nachts und bemerkt jede Bewegung; ein „komischer Kauz“ tanzt aus der Reihe – wie die Vorgänge, die das Tool findet.

- Logo-Idee: Eule/Waldkauz
- CLI: `aluco block tv`
